# Student Habitat - Sprint 1

This branch contains the first 5 features:

1. Email verification on registration
2. Forgot password with email reset link
3. Admin can add, edit, and delete countries
4. Admin can add, edit, and delete cities under a country
5. Structured city information for each city:
   - cost of living
   - climate
   - safety level
   - transport system
   - part-time work availability
