# Student Habitat - Sprint 2

This branch contains the implementation of features 6 to 11:

6. Users can view and filter cities based on available city information
7. Dashboard for easier navigation across the system
8. Users can submit an experience report linked to a specific city
9. Experience submission uses predefined fields such as housing type, monthly budget, cultural challenges, academic environment, and part-time job experience
10. The system displays all experience reports for a selected city
